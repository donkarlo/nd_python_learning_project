    \subsection{Editor}
        \paragraph{Live templates}
            for example if you want that whenever you type ``py`` in .tex files you see a suggestion for
        \begin{minted}{latex}
                \\begin\{minted\}\{python\}
                    s
                \\end\{minted\}
            \end{minted}
            just go to \textit{settings>editor>live templates>}
            and then from the right panel find latex and add ``mnt`` with the code you want. Do not forget to mark reformat and assign \textit{application} to it from low right panel
