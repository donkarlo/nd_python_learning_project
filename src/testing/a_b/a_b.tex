    A/B testing is an online controlled experiment in which real user traffic is randomly split between two (or more) variants, such as a baseline version (A) and a new version (B). Both variants run simultaneously, users see the assigned variant’s outputs, and the variants are compared using predefined metrics (e.g., conversion, satisfaction, error rate) to determine which performs better under production conditions.
