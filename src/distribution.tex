\section{Package}
    \paragraph{install/uninstall}
        navigate to the target folder in terminal while you are in the virtual environment and run
        \begin{minted}{shell}
            pip install -e .
        \end{minted}
        and to uninstall simple run the following anywhere in terminal
        \begin{minted}{shell}
            pip unintall $package_name
        \end{minted}
    \paragraph{running}
        To run a package's \_\_main\_\_.py first go to the virtual environment and  in toml add this (in case the package name is sociomind)
            \begin{minted}{python}
                [project.scripts]
                sociomind = "sociomind.__main__:main"
            \end{minted}
            then install in editable form the package. Then you can  simply call ```sociomind``` anywhere in virtual environment and it runs sociomind.\texttt{\_\_main\_\_}.py in src project. A standard for \texttt{\_\_main\_\_py} is as follows
            \begin{minted}{python}
                def main():
                    print("This is the sociomind main program")
                
                if __name__== "__main__":
                    main()
            \end{minted}

\section{wheel}
    A wheel is a built package format — basically a pre-built, ready-to-install archive for a Python project.
    File extension: .whl
    It’s faster to install than building from source because all the compiling is already done.
    
    Wheels follow the PEP 427 standard.
    
    How to build:
    
    \# do all the follwing commands inside your venv
    
    \begin{minted}{bash}
        cd ~/repos/utilityx_project
        pip install -U build
        #creates dist/.tar.gz and dist/.whl all go into the project build forlder
        python -m build
    \end{minted}
    
    How to install
    
    \begin{minted}{bash}
    pip install dist/utilityx-1.0.0-*.whl
    \end{minted}
