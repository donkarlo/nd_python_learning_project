    \maketitle
    Is responsible to recieve HTTP request and build an HTTP response
    
    The view performs the following tasks:
    
    \begin{itemize}
        \item Retrieves JSON data from the request.
        \item Runs the serializer to validate the input.
        \item Calls the appropriate service or repository.
        \item Converts the result into JSON.
        \item Returns the appropriate HTTP status code.
        \item View classes must be named and filed according to the url patterns we define in url for each url
    \end{itemize}
